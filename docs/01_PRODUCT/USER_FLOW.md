# User Flow
## Student
Login demo → set pseudonym → feed → search hashtag → detail → reply/post → notification.
Materi → course → meeting → materi/arsip diskusi/sumber belajar.
Ruangan → List/Map → detail → foto/jadwal → request → PENDING → notifikasi keputusan → status/alasan.

## CDC
Dashboard → notification/pending queue → detail request + identitas → cek konflik → approve atau reject dengan alasan → update timetable → notify student.
Kalender → pilih minggu → lihat event per ruang → detail. Pengelolaan jadwal hanya untuk petugas berwenang.

## Lecturer
Dashboard → today's classes → detail kelas → lokasi/denah → materi/arsip → insight agregat → acknowledgement. Tidak ada composer/reply.

## Empty/error
Jadwal kosong: “Jadwal belum tersedia”. Foto kosong: “Foto ruangan belum tersedia”. Mapping belum ada: jangan highlight; List tetap tersedia. Search kosong: reset filter. Konflik: minta waktu lain.
