# Definition of Done
Task DONE jika sesuai PRD/design; acceptance criteria terpenuhi; role/privacy diuji; DEMO data dilabeli; loading/empty/error/success ditangani; test relevan dijalankan; lint/typecheck/build bila tersedia; tidak ada error tersembunyi; tidak ada secret; file perubahan dan docs dicatat; known limitations dijelaskan.
Release: Student journey, CDC approval, Lecturer privacy, conflict tests, notification tests, responsive review, production build, DEMO labels, SSO/API limitation.
