description: Diagnosis root cause dan perbaikan minimal.
---
Catat error dan reproduksi; identifikasi file; klasifikasikan syntax/type/runtime/network/auth/data/config; cari root cause; pilih perubahan minimal; jalankan failing test dan regression. Laporkan file, sebab, fix, hasil. Jangan tampilkan key, ubah provider, hapus data, atau jalankan destructive command.
